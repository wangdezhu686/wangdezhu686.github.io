给数模论文里的每个数字留一条回去的路

Created2026-11-27|Updated2026-11-27|软件与工具
|Post Views:

数模论文改到最后一版，表格里的误差究竟来自哪次计算？为了能在交稿前回答这个问题，我在已有的建模工作流上加了一层核查。先登记原始输入和每批样本的用途，再把论文中的数字对应到计算输出。这样，改动数据或模型之后，可以沿着记录找到需要重算的量，也能找到需要一起更新的图表和段落。

我把封存盲测也放进了同一套流程。建模前就标明哪些样本用于开发、哪些留到最终评估，把封存用的参考材料列在禁止读取的范围里。验证记录会单独列出缺少条件的检查项，方便人工复核。上游 MathModelAgent 提供了从赛题分析到论文写作的工作流，我在此基础上补充了样本登记、数字追溯和验证工具。项目 README · 上游 MathModelAgent

给 Freeciv 加一个可以用视线选点的圆环
在 Freeciv 的等距地图上，视线停在两块地的交界处时，圆环该选哪一块？我把选点拆成三个动作。按 F1 唤起圆环，让它吸附到附近可选的位置，再按空格确认。想反悔时按 Esc 就能退出。平时浏览地图，视线经过哪一格都不会触发操作。 为了让圆环在边界附近稳下来，程序会先平滑输入坐标，等相邻位置的距离优势足够明显才切换。我在 Windows 上用鼠标模拟视线，走通了从启动游戏到完成一局的流程。外部输入程序可以通过单独的接口送入坐标和确认事件。仓库也附了 RK3576 的 ARM64 构建脚本，板上运行和输入延迟仍待实机验证。项目说明与测试记录
